# TrueBlue | Instant Water Quality Assessment

TrueBlue is a web-based water quality assessment platform developed using Python and Django. It analyzes water quality parameters and provides instant results, classifying water as safe, moderate, or unsafe. The platform also includes an interactive chatbot for assistance, nearby water quality information, complaint management, and feedback functionality.

### Features
- Instant Water Quality Results
- Water Quality Classification
- Interactive Chatbot Assistance
- Nearby Water Quality Information
- Complaint Management
- Feedback System

### Technologies Used
Python | Django | HTML | CSS | JavaScript | MySQL
